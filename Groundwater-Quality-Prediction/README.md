# Groundwater Quality Prediction

## Project Overview

This project focuses on predicting the Groundwater Quality Feasibility Index (IKKA) in Jakarta using Grey System Theory, specifically the GM(1,7) model.

## Methodology
- Data Preprocessing
- Grey System Theory
- GM(1,7) Prediction Model
- Model Evaluation

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
