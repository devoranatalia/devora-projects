# PDRB Jakarta Barat Prediction & Visualization

## Project Overview
A web-based PDRB prediction and visualization project developed during an internship at BPS Jakarta Barat.

This project uses Linear Regression to predict Gross Regional Domestic Product (PDRB) based on historical data from 2020–2024 across 17 economic sectors.

## Objectives
- Analyze historical PDRB data.
- Predict PDRB for 2025–2026.
- Present economic data through interactive visualizations.

## Tools & Technologies
- Python
- Linear Regression
- MySQL
- Metabase
- HTML, CSS, JavaScript
